#### Exemplo 2: Matriz, Strings e Contagem
**Problema:** Dada uma grade de N linhas e M colunas de caracteres, conte quantos caracteres '1' existem.
**Entrada:**
```
2 3
101
010
```
**Saída:**
```
3
```
**Solução esperada:**
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        if (!sc.hasNextInt()) return;

        int n = sc.nextInt();
        int m = sc.nextInt();

        long count = 0;
        for (int i = 0; i < n; i++) {
            String row = sc.next();
            for (int j = 0; j < row.length(); j++) {
                if (row.charAt(j) == '1') {
                    count++;
                }
            }
        }

        System.out.println(count);
    }
}
```

#### Exemplo 3: Grafos, Indexação 1-Based, Ordenação e Formatação de Saída
**Problema:** Dado um grafo não-direcionado com N vértices (indexados de 1 a N) e M arestas, liste os vizinhos do vértice 1 em ordem crescente, separados por espaço.
**Entrada:**
```
4 3
1 3
1 2
3 4
```
**Saída:**
```
2 3
```
**Solução esperada:**
```java
import java.util.Scanner;
import java.util.List;
import java.util.ArrayList;
import java.util.Collections;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        if (!sc.hasNextInt()) return;

        int n = sc.nextInt();
        int m = sc.nextInt();

        // Indexação 1-based: aloca tamanho n + 1 para evitar IndexOutOfBoundsException
        List<List<Integer>> adj = new ArrayList<>(n + 1);
        for (int i = 0; i <= n; i++) {
            adj.add(new ArrayList<>());
        }

        for (int i = 0; i < m; i++) {
            int u = sc.nextInt();
            int v = sc.nextInt();
            adj.get(u).add(v);
            adj.get(v).add(u);
        }

        List<Integer> neighbors = adj.get(1);
        Collections.sort(neighbors);

        // Formatação sem espaço residual no final da linha
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < neighbors.size(); i++) {
            if (i > 0) sb.append(" ");
            sb.append(neighbors.get(i));
        }
        System.out.println(sb.toString());
    }
}
```
