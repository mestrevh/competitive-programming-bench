#### Exemplo 1: I/O Básico e Prevenção de Overflow
**Problema:** Leia dois inteiros e imprima a soma deles.
**Entrada:**
```
1000000000 2000000000
```
**Saída:**
```

```
**Solução esperada:**
```c

int main(void) {
    long long a, b;
    if (scanf("%lld %lld", &a, &b) == 2) {
        printf("%lld\n", a + b);
    }
    return 0;
}
```

#### Exemplo 2: Matriz, Strings e Contagem
**Problema:** Dada uma grade de N linhas e M colunas de caracteres, conte quantos caracteres '1' existem.
**Entrada:**
```
2 3
101
010
```
**Saída:**
```
3
```
**Solução esperada:**
```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n, m;
    if (scanf("%d %d", &n, &m) != 2) return 0;

    char *row = (char *)malloc((m + 5) * sizeof(char));
    long long count = 0;
    for (int i = 0; i < n; i++) {
        scanf("%s", row);
        for (int j = 0; j < m; j++) {
            if (row[j] == '1') {
                count++;
            }
        }
    }
    free(row);

    printf("%lld\n", count);
    return 0;
}
```

#### Exemplo 3: Grafos, Indexação 1-Based, Ordenação e Formatação de Saída
**Problema:** Dado um grafo não-direcionado com N vértices (indexados de 1 a N) e M arestas, liste os vizinhos do vértice 1 em ordem crescente, separados por espaço.
**Entrada:**
```
4 3
1 3
1 2
3 4
```
**Saída:**
```
2 3
```
**Solução esperada:**
```c
#include <stdio.h>
#include <stdlib.h>

int cmp_int(const void *a, const void *b) {
    int va = *(const int *)a;
    int vb = *(const int *)b;
    return (va > vb) - (va < vb);
}

int main(void) {
    int n, m;
    if (scanf("%d %d", &n, &m) != 2) return 0;

    int *neighbors = (int *)malloc((m + 1) * sizeof(int));
    int deg = 0;

    for (int i = 0; i < m; i++) {
        int u, v;
        scanf("%d %d", &u, &v);
        if (u == 1) {
            neighbors[deg++] = v;
        } else if (v == 1) {
            neighbors[deg++] = u;
        }
    }

    qsort(neighbors, deg, sizeof(int), cmp_int);

    for (int i = 0; i < deg; i++) {
        if (i > 0) printf(" ");
        printf("%d", neighbors[i]);
    }
    printf("\n");

    free(neighbors);
    return 0;
}
```
